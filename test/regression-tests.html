這一頁把 ../index.html 載進來，直接呼叫它裡面**真正的函式**（不是複製一份）， 然後把每一個案例的「輸入 → 呼叫哪一支 → 預期 → 實際」全部印出來。 每次改完 index.html 就重開這一頁。
這一頁必須用網址開啟（https:// 或 http://），不能用 file:// 直接雙擊。
瀏覽器的同源政策不允許 file:// 的頁面去讀另一個 file:// 頁面的內容，測試就拿不到那些函式。
最簡單的做法：把 index.html 與 tests/regression-tests.html 一起放到 GitHub Pages，然後開 https://你的網址/tests/regression-tests.html。
