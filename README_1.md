# 台股動物法則理財儀表板

單一 HTML 檔的台股持倉儀表板。開啟後只回答兩個問題：
**我賺賠多少錢？** 以及 **現在該不該賣？**

**網站：** https://chchin44-bot.github.io/profound-liger-e46917/

- 資料來源：FinMind（台灣證交所公開資料）
- 全部運算在你的瀏覽器裡完成，成本價與持股**不會離開你的裝置**
- 離線可用：把 `index.html` 存到手機或電腦，直接打開就能看

---

## ⚠️ 工程契約：`index.html` 是唯一主檔

日常修改直接改 `index.html`，不要改 `source.html` 再重建。

```
改 index.html  →  跑測試  →  ./sync-source.sh  →  commit  →  push
```

`source.html` 是**由 `index.html` 反推出來的衍生檔**（把內嵌的 Tailwind CSS 與
Chart.js 換回佔位符），只是為了好讀、好比對。它**不是**修改入口。

> 為什麼要立這條規則：以前兩份都被當成正本，最大的風險是有人拿比較舊的
> `source.html` 重新 build，把已經修好的 `index.html` 蓋掉。
> 所以 `build.sh` 現在預設拒絕執行，要 `REBUILD_FROM_SOURCE=1` 才放行。

## 這一頁的四層架構

| 層 | 回答什麼 | 在哪裡看 |
|---|---|---|
| 第一層 | 發生什麼事？ | 動物標籤 🐂🐻🐋🐊 —— **只描述狀態，不是買賣指令** |
| 第二層 | 現在價格在哪？ | 便宜／合理／偏貴參考價、季線、布林區間 |
| 第三層 | 照這套規則可以怎麼做？ | 調倉區間與出場統計 —— **會給具體數字** |
| 第四層 | 這些建議有什麼限制？ | 每個門檻旁的「證據程度」與「⚖️ 門檻與證據」分頁 |

本頁**會**提供價格區間與操作參考，但不把單一個動物標籤當成買賣指令；
也**不是**針對個人財務狀況量身制定的投資建議，不推介個股、不保證報酬。

## 內建自我測試

網址後面加上 `#selftest`：

```
https://chchin44-bot.github.io/profound-liger-e46917/#selftest
```

會跑 30 項帳本與不變量測試（含 8 條不變量 × 200 本隨機帳本），
不需要安裝任何東西。**看到 `PASS 30 FAIL 0` 就是好的。**

## 出事的時候

1. 先跑 `tools/staleguard.sh`，確認底稿有沒有被換成舊版。**對不上就先停手。**
2. 從這個 repo `git clone` 或直接下載，就是完整的一份。
3. 萬一只剩 `index.html`：它可以反推回 `source.html`
   （把 `<style>…</style>` 到緊接著的 `</script>` 換成 `@@ASSETS@@`、
   版本標記換成 `@@BUILD@@`）。前後做過四次，每次 rebuild 都 byte-identical。
   但**反推得回產品，反推不回測試**——所以測試一定要進版控。
